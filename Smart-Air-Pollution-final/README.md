# Smart Air Pollution Health Impact Analytics System

A Flask + Random Forest web application for pollution-based health-risk screening and travel pollution analysis.

## Features

- Current-location analysis using browser geolocation
- Reverse geocoded city/state name
- Search any city/town
- Seven pollutant indicators: PM2.5, PM10, NO2, NH3, CO, SO2, O3
- Saved Random Forest health-risk screening: Low / Moderate / High / Very High
- Potential health-impact interpretation
- Risk-aware precautions
- Next-hour destination forecast screening
- Road route using OSRM
- Travel-mode selection
- Route pollution sampling at multiple points
- ETA-based hourly forecast screening along the route
- Average/max PM2.5 and elevated-risk route points
- Interactive Leaflet route map
- Start vs destination pollution chart
- Responsive desktop/mobile UI

## Required model files

Place these two files in the project root:

- `random_forest_model.pkl`
- `features.pkl`

They are your trained model artifacts and are not regenerated by the web application.

## Run locally on Windows

Open Command Prompt/PowerShell in the project folder.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

For location access, allow the browser permission.

## Important model-version note

The requirements pin scikit-learn to 1.6.1 because the trained model was created with that version. This avoids the model-version warning/error that can occur when loading a pickle created with another scikit-learn version.

## Deploy on Render

1. Put all project files, including both `.pkl` files, into one GitHub repository.
2. Create a Render **Web Service** from that repository.
3. Runtime: Python.
4. Build command:

```bash
pip install -r requirements.txt
```

5. Start command:

```bash
gunicorn app:app
```

6. Deploy.
7. Open the generated HTTPS URL and allow browser location permission.

The Flask application listens on the Render-provided `PORT` environment variable.
